---
name: Archived member visibility
description: Archived accounts are hidden from normal member displays and shown only for explicit restoration.
---

Hide archived players from all member displays, other than when explicitly requested to unarchive.

**Why:** The user requested this as the standing visibility rule for this app.

**How to apply:** Normal lists and selectors must exclude archived accounts by default. Keep an explicit restoration view. Hide rather than delete accounts, stored group links, or historical snapshots.
